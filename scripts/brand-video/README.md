# Arabic teaser: «إنّه يومٌ جديد — اللعبة تغيّرت»

A 21-second vertical film (1080×1920, 30 fps, with sound), rendered to
`public/video/ouaqt-new-day-ar.mp4`.

A word at a time sits on the crest of a curved horizon while the material
under it cuts from one texture to the next: dunes, zellige, the Fes tannery
vats, a handwritten ledger, a watch dial, saffron, brass, a mashrabiya. The
cuts get faster, a burst of single frames marks the change, then the sky goes
dark, the logo draws itself ring by ring like a clock hand, and the sun comes
up behind it. Clock ticks land on every cut; the logo's four rings play a D
major chord.

Everything is generated by `render.py`: textures, type, logo animation and
soundtrack. There is no stock footage or music, so there are no licences to
track.

## Render

```bash
pip install numpy opencv-python-headless pillow scipy fonttools brotli imageio-ffmpeg
python scripts/brand-video/render.py                          # the film
python scripts/brand-video/render.py --sheet /tmp/sheet.png   # one still per texture
python scripts/brand-video/render.py --out /tmp/f.mp4 --frames 150,300,560   # PNG stills
```

It takes a couple of minutes. The fonts (Noto Naskh Arabic for the words,
Aref Ruqaa for the ledger's handwriting) are fetched from npm the first time
into `.cache/`. The logo comes from `public/logo-ouaqt-dark-ink.png`.

## Changing it

At the top of `render.py`:

- `WORDS`: the four words, in order.
- `PRE`, `W1` … `W4`: how long each cut lasts, in frames, grouped by the word on screen.
- `ORDER`: which texture each cut shows.
- `LOGO_HOLD`, `SUNRISE`, `END_HOLD`: the ending.

The film is deterministic: the same code gives the same frames.
